✦ About the Project

Solving Emergency Medicine Stockouts

MediTraceX is a full-stack healthcare technology platform built to solve the critical challenge of emergency medicine stockouts and pharmaceutical access barriers.

The platform combines real-time medicine search with GPS-based pharmacy discovery, AI-powered demand forecasting, and stock-out risk classification — enabling patients, pharmacists, and administrators to find, verify, and reach essential medicines faster.

Built with a 3-tier role-based access system (Patient → Pharmacist → Admin), MediTraceX delivers a comprehensive ecosystem spanning a React web dashboard, an Android native app, and a robust FastAPI backend.
